# Python 自習課題｜繰り返しを復習しよう！

## 構成
アップロードされた「python-lesson3-practice-site(1).zip」のデザイン・画面構成・JSの動きを引き継ぎ、題材と問題数のみ更新しています。

- 基本問題 3問：文章の繰り返し → 数字の表示 → 3回サイコロ
- 演習問題 1問：サイコロチャレンジ（5以上なら成功、4以下なら失敗）
- チャレンジ問題 2問：成功回数を数える・6が出るまでwhile
- 基本問題3問完了時点で今日の目標達成
- 各問題：問題文／条件／出力例／できたら試そう／ヒント／「動かせた！」
- 必要な問題のみ、折りたたみのスタート用コード（コピー可能）

## ファイル
- index.html：出題内容
- styles.css：元サイトのデザインをそのまま使用
- app.js：基本問題3問に合わせ進捗表示と保存キーを変更
- favicon.svg：元サイトをそのまま使用

## 公開方法
既存サイトを上書きしたくない場合、新しい GitHub リポジトリを作成し、サイトフォルダの中身をリポジトリのルートへアップロードしてください。Settings → Pages で main / root を公開元に指定します。

授業資料リンクは https://nonakagw.github.io/python-lesson4-site/ に設定しています。公開先に応じて変更可能です。

## 動作・注意
- HTML/CSS/JavaScriptのみで動作し、npmやビルドは不要。
- Pythonコードの実行はTech Nexus上で行う。
- チェック結果はブラウザのlocalStorageへ保存（学校端末の設定で制限される場合は保存されない）。
- プログラム内容の送信や自動採点は行わない。
- 教材内に「第○回」という課題回数の表記を含まない。
