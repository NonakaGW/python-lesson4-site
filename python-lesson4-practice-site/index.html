基本問題 · for / range

同じ文章を5回表示しよう

約5分

for と range() を使って、「Pythonがんばるぞ！」を5回表示しよう。

作るプログラムの条件

  1. for と range() を使う
  2. 「Pythonがんばるぞ！」を5回表示する
  3. print() を5行並べるのではなく、繰り返しを使う
出力例
Pythonがんばるぞ！

Pythonがんばるぞ！
Pythonがんばるぞ！
Pythonがんばるぞ！

for i in range(5):
    print("Pythonがんばるぞ！")

03

基本問題 · for / random

サイコロを3回振ろう

約10分

random と繰り返しを組み合わせて、サイコロを3回振るプログラムを作ろう。

作るプログラムの条件

  1. random.randint(1, 6) で1〜6の数字を選ぶ
  2. for を使って3回繰り返す
  3. 「1回目：3」のように、何回目かと出た数字を表示する
出力例（一例）
1回目：3
2回目：6
3回目：2
※数字は毎回変わるよ。
できたら試そう

もう一度実行してみよう。1〜6の中で、さっきとは違う数字が出たかな？

スタート用コードを見る（必要な人だけ）

ここから始めてもOK。続きを自分で書いてみよう！

import random

number = random.randint(1, 6)
print(number)
ヒント①　何を繰り返す？

for i in range(3): の内側で number = random.randint(1, 6) を実行しよう。

ヒント②　「何回目」と表示するには？

i は0から始まるので、i + 1 を使おう。

print(f"{i + 1}回目：{number}")

import random を一番上に書くことも忘れずに。

04

演習問題 · for × if × random

サイコロチャレンジを作ろう！

約15分

問題③を改造して、繰り返し × 条件分岐のゲームを作ろう！

作るプログラムの条件

  1. サイコロを5回振る
  2. 出た数字が5以上なら「成功！」と表示する
  3. それ以外なら「失敗…」と表示する
  4. 何回目かと、サイコロの数字も表示する
出力例（一例）
1回目：3
失敗…
2回目：5
成功！
3回目：1
失敗…
4回目：6
成功！
5回目：2
失敗…
※数字は毎回変わるよ。結果を表示する形が少し違っても、5回の成功・失敗が分かればOK！
できたら試そう

range(5) を range(10) に変えると、10回チャレンジになるかな？

スタート用コードを見る（必要な人だけ）

ここから始めてもOK。続きを自分で書いてみよう！

import random

for i in range(5):
    number = random.randint(1, 6)
    print(f"{i + 1}回目：{number}")

    # ここに条件分岐を書こう
ヒント①　条件分岐はどこに書く？

サイコロを振って数字を表示したあとに、if と else を書こう。if は for の内側に入るよ。

ヒント②　「5以上」はどう書く？
if number >= 5:
    print("成功！")
else:
    print("失敗…")

>= は「以上」という意味。and や or は使わなくてOK！

サイコロチャレンジを改造して、成功した回数を最後に表示しよう。

B

CHALLENGE ②

6が出るまで振り続けよう

今度は、何回振るか決めずに6が出るまでサイコロを振り続けてみよう。

条件

  1. while を使って、6が出るまで繰り返す
  2. 「何回目：出た数字」を表示する
  3. 6が出たら終了して、何回で6が出たか表示する
出力例（一例）
1回目：4
2回目：1
3回目：5
4回目：6
4回で6が出ました！
※6が出るまでの回数は毎回違うよ。
できたら試そう

出るまで振る数字を6から1に変えることはできるかな？

ヒント①　whileの条件を思い出そう

while number != 6: は「number が6ではない間、繰り返す」という意味だよ。

ヒント②　最初の準備は？

繰り返す前に number = 0 と count = 0 を作ろう。while の中で数字を選び、回数を1増やすよ。
